# Interview Strategy Memory

Long-term strategy knowledge distilled from interview sessions.
Each entry links to a topic file with full details.

- [Junior Implementation Trace Probe](junior_implementation_trace_probe.md) - Ask junior candidates to reconstruct one concrete implementation path before abstract trade-offs.
- [Junior Recovery Hint Strategy](junior_recovery_hint_strategy.md) - Use a bounded hint to recover signal when junior answers are vague or nervous.
- [Junior System Design Component Trace](junior_system_design_component_trace.md) - Evaluate junior system design by tracing one component interaction instead of asking for a full architecture.
- [Junior System Design Data Consistency](junior_system_design_data_consistency.md) - Probe junior system design through a small consistency scenario with clear state changes.
- [Senior Trade-off Stress Probe](senior_tradeoff_stress_probe.md) - Stress senior answers by changing one constraint and asking what they would sacrifice.
- [Senior Failure Mode Probe](senior_failure_mode_probe.md) - Test senior candidates by forcing their design through realistic failure modes.
- [Coding Quality Change Risk Probe](coding_quality_change_risk_probe.md) - Evaluate coding quality by asking how the candidate safely changes a live code path.
- [Coding Quality Review Signal Probe](coding_quality_review_signal_probe.md) - Use code review behavior to surface maintainability, collaboration, and judgment.
- [Product Metric Boundary Probe](product_metric_boundary_probe.md) - Probe product thinking by asking which metric should not be optimized blindly.
- [Product Trade-off Discovery Probe](product_tradeoff_discovery_probe.md) - Ask candidates to explain how they discovered and resolved a product trade-off.
- [Project Impact Evidence Probe](project_impact_evidence_probe.md) - Turn project stories into measurable evidence instead of broad responsibility claims.
- [Project Anchor Deepening Strategy](project_anchor_deepening_strategy.md) - Use the selected project anchor as the spine for technical and system follow-ups.
- [Budget-aware Dimension Switch](budget_aware_dimension_switch.md) - Switch dimensions when extra depth is less valuable than covering an unvisited signal.
- [Weak Answer Concrete Hint](weak_answer_concrete_hint.md) - Recover weak answers with one concrete anchor before concluding the candidate lacks the skill.

- [Follow-up Timing](feedback_followup_timing.md) — When to deepen vs switch dimensions based on answer quality signals
- [Evasive Answer Patterns](pattern_evasive_answers.md) — How to handle candidates who give vague or rehearsed answers
- [Senior System Design Strategy](strategy_senior_system_design.md) — Deep follow-ups outperform surface-level questions for senior candidates in system design
