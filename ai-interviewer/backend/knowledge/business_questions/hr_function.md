# HR / 职能 题库

面向 C 端用户准备 HR / 职能岗（招聘 / HRBP / 员工关系 / 组织发展 / 行政 / 法务支持）面试的检索种子题。题目以"请结合你过往真实负责的业务场景"为主轴，鼓励候选人讲具体案例而非抽象方法论。每组题目包含 base + 2-3 个渐进式 follow-up，配套 2-3 条评分要点。

难度标签：
- `intro` 开场或背景题
- `standard` 主战场，需要讲清"问题 / 动作 / 取舍 / 结果"
- `deep_probe` 深挖追问，要求量化或暴露真实判断过程

## 维度：人才招聘 (talent_acquisition)

### 1. 岗位理解
- **base** [intro]：你接到一个 JD 后，怎么判断这个岗位的"真实需求"和 JD 上写的可能不一样？
- **follow-up** [standard]：你和业务部门 / Hiring Manager 对岗位预期不一致时，怎么对齐？
- **follow-up** [deep_probe]：你最近一次主动改写过 JD 是什么情况？改完之后效果差异大吗？
- **评分要点**：能否区分"JD 上的诉求"和"业务真实痛点"；对齐过程是否结构化（成功画像 / 关键能力 / 必备 / 加分）；能承担推动业务方调整预期。

### 2. 寻访策略
- **base** [standard]：你过往招聘最难填的岗位是哪个？为什么难、你用了什么策略？
- **follow-up** [deep_probe]：寻访过程中接触了多少候选人才找到合适的？这个比例对你的招聘策略有什么启发？
- **评分要点**：能否量化漏斗（接触 / 沟通 / 面试 / offer / 入职）；策略调整是否结合"难度 × ROI"。

### 3. 面试评估
- **base** [standard]：你怎么帮助 Hiring Manager 在面试里评估出候选人的真实水平、避免被表达力误导？
- **follow-up** [deep_probe]：你见过"面试表现好但入职后表现差"的候选人吗？事后复盘问题在哪？
- **评分要点**：能否设计行为面试 / 案例 / 工作样本；理解面试信号的局限性并多源交叉验证。

### 4. Offer 谈判
- **base** [standard]：候选人在 offer 阶段提出加薪 20% 或 counter offer 时，你怎么处理？
- **follow-up** [deep_probe]：你有过 offer 没谈下来的关键候选人吗？事后看是钱、岗位、还是别的？
- **评分要点**：能否区分"价格异议"和"价值不匹配"；处理过程是否兼顾候选人体验和组织一致性。

### 5. 候选人体验
- **base** [standard]：候选人即使被拒也应该有不差的体验。你过往做过哪些动作来管理候选人体验？
- **follow-up** [deep_probe]：候选人体验差的负面声音曾经反过来影响过你们招聘吗？怎么修复的？
- **评分要点**：能否把候选人体验当成长期品牌资产；处理负面声音时分立即响应和系统改进。

## 维度：员工关系 (employee_relations)

### 6. 沟通与建立信任
- **base** [intro]：HRBP 角色里，建立和员工的信任是基础。你过往是怎么做的？
- **follow-up** [standard]：你处理过最棘手的一次员工沟通是哪个？为什么棘手？
- **follow-up** [deep_probe]：那次沟通让你之后处理类似事情的方式有什么变化？
- **评分要点**：信任建立是否结合"专业 + 同理心 + 边界感"；案例描述是否具体到对话节点。

### 7. 冲突处理
- **base** [standard]：员工和员工 / 员工和上级冲突时，你的介入边界在哪？
- **follow-up** [deep_probe]：你介入过最严重的一次冲突是什么？最后双方关系怎么样？
- **评分要点**：能否区分"应介入"和"应放手让自然解决"；处理过程是否中立而非站队。

### 8. 离职管理
- **base** [standard]：你处理过让你印象深的员工主动离职吗？面谈里通常听到什么、怎么用这些信号？
- **follow-up** [deep_probe]：高绩效员工提出离职但你想挽留——挽留的边界在哪？挽留成功的案例多还是失败的多？
- **评分要点**：离职面谈是否能挖到真实原因（不是表面"个人发展"）；挽留是否结合个体诉求和组织代价。

### 9. 困难谈话
- **base** [standard]：你负责过让一位绩效不达标的员工离开吗？怎么准备的、怎么谈的？
- **follow-up** [deep_probe]：那次谈话之后这位员工的状态如何？事后复盘下你的准备有什么不足？
- **评分要点**：能否兼顾"组织决定的明确性"和"个体尊严"；准备是否充分（事实 / 时间线 / 替代方案）。

## 维度：组织发展 (organization_development)

### 10. 组织诊断
- **base** [intro]：你做过组织诊断吗？通过什么信号判断一个团队是健康的还是有问题的？
- **follow-up** [standard]：你最近一次诊断到团队问题是哪个？发现路径是怎么样的？
- **follow-up** [deep_probe]：诊断之后你给业务方的建议被采纳了吗？没采纳的部分是因为什么？
- **评分要点**：诊断是否多维度（产出 / 协作 / 流动 / 文化）；面对建议未采纳能否区分"专业判断不被认可"和"建议本身不够 actionable"。

### 11. 培训设计
- **base** [standard]：你设计过什么培训项目？怎么决定培训内容的优先级？
- **follow-up** [deep_probe]：培训上完之后行为真的改变了吗？怎么衡量？
- **评分要点**：培训设计是否解决具体能力缺口；衡量是否结合"行为变化"而非"出勤率 / 满意度"。

### 12. 绩效管理
- **base** [standard]：你过往参与过的绩效管理流程是什么样？校准会上你扮演什么角色？
- **follow-up** [deep_probe]：见过绩效结果"和实际表现明显不符"的情况吗？是流程问题还是评估者偏差？
- **评分要点**：能否区分流程问题和人为偏差；理解校准的政治和专业双重属性。

### 13. 人才发展
- **base** [standard]：你帮助过哪个员工实现明显成长？关键的几个动作是什么？
- **follow-up** [deep_probe]：成长背后是员工本身潜力 + 你的推动？还是主要靠机会？怎么区分？
- **评分要点**：能否承认"成长不全是 HR 推动"；理解机会、潜力、辅导三者的关系。

## 维度：制度合规 (policy_compliance)

### 14. 政策设计
- **base** [intro]：你过往参与过哪类政策 / 制度的设计或修订？流程是什么样？
- **follow-up** [standard]：政策设计里最容易踩坑的是什么？比如设想很好但执行时漏洞百出。
- **follow-up** [deep_probe]：你最近修订过的一项政策是因为什么？修订前后效果对比？
- **评分要点**：能否区分"政策设计完美"和"执行可落地"；理解政策的"边界 + 弹性"。

### 15. 劳动法合规
- **base** [standard]：你过往遇到过最复杂的劳动法相关问题是什么？怎么处理的？
- **follow-up** [deep_probe]：处理过程中和外部律师 / 内部法务的协作怎么样？
- **评分要点**：能否识别合规边界；遇到不确定情况是否倾向于多方核对而非自行判断。

### 16. 风险识别
- **base** [standard]：你过往识别过哪些组织风险？给到管理层之后他们怎么处理？
- **follow-up** [deep_probe]：被识别但没被处理的风险后来真的爆发过吗？怎么复盘？
- **评分要点**：能否预见"未爆发的风险"；面对管理层不重视时是否有结构化推进方式。

### 17. 数据隐私 / 保密
- **base** [standard]：HR 接触大量敏感数据。你怎么管理这些数据的边界？比如薪资 / 绩效 / 离职原因？
- **follow-up** [deep_probe]：你见过同事处理敏感数据不当的情况吗？怎么处理的？
- **评分要点**：能否把"保密"当成职业本能；理解信息泄露对组织信任的长期伤害。

## 维度：服务意识 (service_orientation)

### 18. 内部客户思维
- **base** [intro]：HR 的"内部客户"是业务部门 + 员工。这两类的诉求经常冲突。你怎么平衡？
- **follow-up** [standard]：举一个业务诉求和员工诉求冲突的例子，你最后怎么取舍？
- **follow-up** [deep_probe]：取舍之后受影响的一方对你的工作认可度变化吗？长期信任怎么经营？
- **评分要点**：能否在冲突里坚持原则同时兼顾关系；理解 HR 的政治属性。

### 19. 响应与节奏
- **base** [standard]：业务方提出 HR 需求时，你怎么管理响应节奏（紧急 / 重要 / 长期建设）？
- **follow-up** [deep_probe]：你有过被业务方"急活淹没"导致长期项目卡住的经历吗？怎么调整？
- **评分要点**：能否分级响应（24h / 1 周 / 季度）；面对压力是否能 push back 而非被动接活。

### 20. 流程优化
- **base** [standard]：你优化过哪个 HR 流程让效率提升或体验改善的？
- **follow-up** [deep_probe]：优化之后真的有人用吗？怎么知道？
- **评分要点**：优化是否结合用户反馈；能否检验改进真的产生杠杆。

### 21. 跨职能协作
- **base** [standard]：HR 和财务 / 法务 / 行政经常协作。你怎么经营这些协作关系？
- **follow-up** [deep_probe]：跨职能协作里你最常踩的坑是什么？怎么改进的？
- **评分要点**：能否理解每个职能的核心诉求；协作是否有具体的协调机制。

## 通用追问触发器

- 候选人说"我招到了 XX 个人 / 完成了 X 个 offer" → 追问"难填岗位占比？平均 time-to-hire？1 年内留存率？"
- 候选人说"我处理了一次员工纠纷" → 追问"双方现在关系如何？团队对你的处理评价怎么样？"
- 候选人说"我设计了一个新政策" → 追问"政策上线 6 个月后还有人按这个走吗？有没有被悄悄绕过？"
- 候选人说"我做了一次组织诊断" → 追问"诊断报告给到谁？建议采纳率？没采纳的为什么？"
- 候选人说"员工对我满意度高" → 追问"通过什么数据看到的？有没有调研 / 一对一反馈？"
