# 销售 / 商务 题库

面向 C 端用户准备销售 / 商务岗（B2B / B2C 销售、客户经理、商务拓展）面试的检索种子题。题目以"请结合你过往真实负责的客户或交易"为主轴，鼓励候选人讲具体单子而非抽象方法论。每组题目包含 base + 2-3 个渐进式 follow-up，配套 2-3 条评分要点。

难度标签：
- `intro` 开场或背景题
- `standard` 主战场，需要讲清"客户画像 / 推进动作 / 关键人 / 结果"
- `deep_probe` 深挖追问，要求量化或暴露真实博弈过程

## 维度：客户发现 (customer_discovery)

### 1. 目标客户画像
- **base** [intro]：你过往负责的产品 / 服务，理想客户长什么样？你是怎么得出这个画像的？
- **follow-up** [standard]：你拒绝过一些"看起来能签但其实不是目标客户"的单子吗？为什么？
- **follow-up** [deep_probe]：拒绝那个单子之后有没有后悔过？或者反过来——勉强签了但合作不顺利的？
- **评分要点**：客户画像是否结合规模 / 行业 / 痛点 / 预算 / 决策链；能否承担"主动放单"以保持客户健康度。

### 2. 客户开拓渠道
- **base** [standard]：你过往最有效的找客户渠道是什么？为什么这个比别的好？
- **follow-up** [standard]：渠道的转化漏斗大致什么样？从触达到首次约见、到 POC、到签单各阶段的转化率？
- **follow-up** [deep_probe]：你最近一次新增了哪个渠道？为什么开拓它、效果如何？
- **评分要点**：能否量化漏斗（不是定性"还行"）；渠道选择是否结合成本 / 速度 / 客户质量。

### 3. 关键人识别
- **base** [standard]：在 B2B 销售里，决策链通常是多人。你怎么识别一个客户里"谁说了算、谁能说不、谁帮你说话"？
- **follow-up** [deep_probe]：识别错关键人之后再纠正的成本有多大？讲一次踩坑的经历。
- **评分要点**：能否区分使用者 / 决策者 / 把关者 / 影响者；能否承认识别错误的代价并复盘原因。

### 4. 需求挖掘
- **base** [standard]：第一次和客户深聊时，你怎么挖出客户没主动说出口的真实诉求？
- **follow-up** [deep_probe]：有没有过客户口头说要 X 但你坚持挖到 Y 才是真问题、最后按 Y 做方案的？结果如何？
- **评分要点**：挖掘技巧是否结合提问框架（SPIN / 5W / 业务影响）；能否区分客户的"诉求"和"症状"。

## 维度：方案匹配 (solution_matching)

### 5. 方案设计
- **base** [intro]：你给客户做方案时，怎么从一堆产品能力里挑出和这个客户最匹配的几个？
- **follow-up** [standard]：方案讲完之后，客户最常追问的问题类型是什么？你怎么应对？
- **follow-up** [deep_probe]：你做过最复杂的一个方案，涉及多少模块、多少人月、谈了多久？为什么这么难？
- **评分要点**：方案设计是否真的"为客户量身"（不是产品手册剪贴）；能否预判客户疑问并提前准备。

### 6. 价值量化
- **base** [standard]：客户问"你这个东西能给我带来什么"，你怎么把价值量化给他？
- **follow-up** [deep_probe]：你给的量化数字客户认可吗？有没有过被客户挑战 ROI 假设的经历？
- **评分要点**：价值量化是否分维度（直接收入 / 成本节约 / 风险降低 / 战略价值）；能否承担被挑战并修正假设。

### 7. 竞争对比
- **base** [standard]：客户问"你和竞品 X 比有什么差别"，你怎么答？
- **follow-up** [deep_probe]：你输给过竞品吗？事后复盘是产品差距、还是销售推进的问题？
- **评分要点**：能否真正讲清竞品差异（不是贬低对手）；输单复盘是否能区分内外因。

### 8. POC / 试用推进
- **base** [standard]：你做过 POC 阶段吗？怎么设计 POC 让客户最快看到价值？
- **follow-up** [deep_probe]：POC 跑成功但没签的单子有过吗？为什么？
- **评分要点**：POC 设计是否结合"快速看到价值的最小验证场景"；能否分析 POC 成功 ≠ 签单的真因。

## 维度：异议处理 (objection_handling)

### 9. 价格异议
- **base** [intro]：客户说"你这个太贵了"，你的第一反应是什么？
- **follow-up** [standard]：你过往遇到过最难处理的价格异议是哪个？最后怎么收场？
- **follow-up** [deep_probe]：当客户的预算确实不够时，你怎么决定是降价、是改方案、还是放弃？
- **评分要点**：能否区分"价格异议"和"价值异议"；处理方式是否结合长期客户价值而非急于降价。

### 10. 时机异议
- **base** [standard]：客户说"我们今年没规划做这个，明年再说"，你怎么应对？
- **follow-up** [deep_probe]：你成功撬动过"客户原本说没规划"的单子吗？关键动作是什么？
- **评分要点**：能否分辨"真没需求"和"优先级低"；撬动方式是否依赖事件驱动（行业变化 / 内部变化）。

### 11. 决策权异议
- **base** [standard]：客户说"我得回去问老板 / 团队再定"，你怎么处理？
- **follow-up** [deep_probe]：你曾经"绕过对接人直接见高层"过吗？这种动作的边界在哪？
- **评分要点**：能否在不破坏对接人关系的前提下推进决策链；理解越级动作的政治风险。

### 12. 信任建立
- **base** [standard]：刚接触的客户对你和你公司不熟，怎么在前几次接触里建立信任？
- **follow-up** [deep_probe]：你做过最快建立信任的一次是怎么做的？事后看是真信任还是表面客气？
- **评分要点**：信任建立是否结合专业表现 / 同理心 / 第三方背书；能否区分浅层好感和深层信任。

## 维度：商务谈判 (negotiation)

### 13. 报价策略
- **base** [intro]：你怎么决定一个单子的报价？是按列表价、按客户预算、还是按价值？
- **follow-up** [standard]：报价之后客户砍价的常见路数是什么？你的回应路径？
- **follow-up** [deep_probe]：你最近一次主动降价是因为什么？降价之后客户怎么反应？
- **评分要点**：报价策略是否结合 BATNA / 锚点 / 价值阶梯；面对砍价是否能在让步和坚守之间找到平衡。

### 14. 多方谈判
- **base** [standard]：当谈判涉及客户多方（业务 / 采购 / 法务）时，你怎么协调内部和外部多方的节奏？
- **follow-up** [deep_probe]：有过被客户的法务 / 采购卡住关键条款的经历吗？怎么破？
- **评分要点**：能否管理"多线程谈判节奏"；面对法务 / 采购的硬条款是否能区分原则和谈判空间。

### 15. 让步与交换
- **base** [standard]：谈判里让步是常态，你怎么决定哪些可以让、哪些不能让？
- **follow-up** [deep_probe]：你做过的最划算的一次"让步换让步"是怎么操作的？
- **评分要点**：是否有"让步等价物"概念（每次让步换回什么）；理解让步本身的信号意义。

### 16. 合同关键条款
- **base** [standard]：合同谈判里，除了价格之外，你最在意哪些条款？为什么？
- **follow-up** [deep_probe]：你曾经因为某个条款没谈好后续吃过亏吗？这个亏对你的合同模板有什么影响？
- **评分要点**：能否识别交付 / 验收 / 付款 / 退出 / 责任 等关键条款；事后是否真把教训写进模板。

## 维度：销售漏斗管理 (pipeline_management)

### 17. 漏斗健康度
- **base** [intro]：你怎么判断你手上的销售漏斗是健康的？看哪些信号？
- **follow-up** [standard]：漏斗里出现过"金额很大但停滞很久"的单子吗？你怎么处理？
- **follow-up** [deep_probe]：你定期做漏斗清理吗？标准是什么？清理之后漏斗效率有没有变化？
- **评分要点**：漏斗健康度是否结合阶段分布 / 停留时间 / 转化率；清理是否有原则（不是凭感觉）。

### 18. 预测能力
- **base** [standard]：销售预测准不准，是销售管理的核心。你怎么提升你自己的预测准确度？
- **follow-up** [deep_probe]：你过往最大的预测偏差是哪一次？为什么会偏？
- **评分要点**：预测是否结合历史转化率 + 客户信号 + 阶段稳定度；能否复盘预测偏差的真因。

### 19. CRM 与数据纪律
- **base** [standard]：CRM 里的数据完整度直接影响管理。你怎么保证自己（或你团队）的 CRM 数据是真实的、及时的？
- **follow-up** [deep_probe]：见过同事在 CRM 里"假更新"或者"压单"的吗？这种行为对团队的代价是什么？
- **评分要点**：能否把 CRM 数据看成长期资产；理解"漂亮数据"和"真实数据"的差异。

### 20. 客户长期经营
- **base** [standard]：签完单之后，你的客户经营动作有哪些？是放手交给 CSM 还是自己继续跟？
- **follow-up** [deep_probe]：你做过续约 / 增购的单子吗？让客户主动加单的关键是什么？
- **评分要点**：是否真把"复购 / 推荐 / 增购"看成 KPI 一部分；理解信任的复利效应。

### 21. 业绩压力下的取舍
- **base** [standard]：季度末业绩压力大时，你怎么平衡"冲短期单子"和"长期客户经营"？
- **follow-up** [deep_probe]：有没有过为了完成 KPI 接了一个事后让你后悔的客户？复盘下当时的判断。
- **评分要点**：能否承担短期压力下不放弃原则；复盘是否真诚（而非"我永远做正确选择"）。

## 通用追问触发器

- 候选人说"我签下了 XX 万 / XX 千万的单子" → 追问"决策周期多长？关键 win moment 在哪一步？客户后来用得怎么样？"
- 候选人说"我和客户关系很好" → 追问"具体好在哪？这个关系帮你拿到过哪些信息或机会？"
- 候选人说"我们的产品比竞品好" → 追问"客户买你不买竞品的真实理由是什么？是产品强还是关系强？"
- 候选人说"我推动了客户做决策" → 追问"具体哪个动作让客户从'再看看'变成'就买你'？"
- 候选人说"我超额完成了 KPI" → 追问"超额部分是来自客户复购、新客户、还是大单？预测准确度怎么样？"
