# 市场 / 品牌 题库

面向 C 端用户准备市场 / 品牌岗（市场经理 / 品牌经理 / 增长营销 / 内容营销 / 渠道运营）面试的检索种子题。题目以"请结合你做过的真实活动 / 项目 / 内容"为主轴。每组题目包含 base + 2-3 个渐进式 follow-up，配套 2-3 条评分要点。

难度标签：
- `intro` 开场或背景题
- `standard` 主战场，需要讲清"洞察 / 策略 / 执行 / 数据"
- `deep_probe` 深挖追问，要求量化或暴露真实判断过程

## 维度：市场洞察 (market_insight)

### 1. 行业 / 用户研究方法
- **base** [intro]：你过往做市场洞察用过哪些方法？最依赖哪一种？为什么？
- **follow-up** [standard]：选一次让你形成关键判断的洞察经历——当时输入是什么、你的判断是什么、最后被验证了吗？
- **follow-up** [deep_probe]：洞察的来源（桌面研究 / 行业访谈 / 用户调研 / 数据分析）之间冲突时，你倾向于相信哪个？为什么？
- **评分要点**：方法选型是否结合成本 / 速度 / 信号质量；能否处理多源信号冲突而非简单选边。

### 2. 竞品分析
- **base** [standard]：你最近一次系统做的竞品分析是哪个？输出长什么样？给到谁、怎么用？
- **follow-up** [deep_probe]：竞品分析里最反直觉的发现是什么？这个发现真的影响了产品/营销策略吗？
- **评分要点**：分析框架是否包含定位 / 产品 / 渠道 / 价格 / 用户口碑；能否避免变成"竞品功能列表对比"。

### 3. 趋势识别
- **base** [standard]：你识别过哪个行业 / 用户行为趋势是别人后来才意识到的？当时你看到了什么信号？
- **follow-up** [deep_probe]：识别趋势之后你具体做了什么？这个动作的回报怎么样？
- **评分要点**：趋势识别是否结合多源信号（搜索数据 / 资本动向 / 头部用户行为）；判断是否真的转化为决策。

### 4. 用户研究的"反直觉"
- **base** [standard]：你做过的用户研究里，有没有过结果和老板 / 团队预设完全相反的？怎么处理？
- **follow-up** [deep_probe]：研究结果反预设但你坚持发布，发布之后团队反应如何？最后这个判断对吗？
- **评分要点**：能否在政治压力下坚持事实；事后能否承认自己的判断也可能错。

## 维度：品牌策略 (brand_strategy)

### 5. 品牌定位
- **base** [intro]：你过往参与过的品牌的定位是什么？这个定位是怎么来的、谁定的？
- **follow-up** [standard]：定位有没有过被市场反馈推翻或重新调整？什么时候调、怎么调？
- **follow-up** [deep_probe]：定位调整时你最担心的是什么？老用户认知怎么处理？
- **评分要点**：定位是否结合用户 / 竞品 / 内部能力；调整是否有节奏（不是大跃进式 rebrand）。

### 6. 品牌一致性管理
- **base** [standard]：品牌在多渠道（投放 / 内容 / 客服 / 活动）传播时，怎么保证调性和价值主张一致？
- **follow-up** [deep_probe]：你处理过品牌"翻车"或者公关危机吗？事后机制怎么改的？
- **评分要点**：是否有 brand book / 调性指南 / review 流程；危机处理是否分"立即响应 / 事后机制"两层。

### 7. 品牌资产沉淀
- **base** [standard]：除了 logo 和 slogan，你过往参与过的品牌还沉淀了哪些可复用的"品牌资产"？
- **follow-up** [deep_probe]：这些资产真的被复用过吗？复用率怎么样？
- **评分要点**：能否区分"品牌物料"和"品牌资产"；理解资产的复用价值。

### 8. 品牌与增长的关系
- **base** [standard]：品牌建设和短期增长有时候节奏不同。你过往是怎么和增长 / 销售团队对齐节奏的？
- **follow-up** [deep_probe]：有过为了短期 GMV 牺牲品牌调性的活动吗？事后值不值？
- **评分要点**：能否处理品牌长期价值和短期 KPI 的冲突；有清晰的取舍标准。

## 维度：营销策划 (campaign_planning)

### 9. Campaign 立项
- **base** [intro]：你独立或者主导跑过一个 campaign 吗？讲讲从立项到上线的关键节点。
- **follow-up** [standard]：立项时你怎么定 campaign 的核心 message 和创意方向？
- **follow-up** [deep_probe]：核心 message 是从用户洞察出发还是从业务目标出发？冲突时怎么处理？
- **评分要点**：立项流程是否结构化（目标 / 受众 / 策略 / 创意 / 渠道 / 预算 / KPI）；message 设计有用户视角而非纯业务话术。

### 10. 创意 brief 与外部协作
- **base** [standard]：你怎么写 creative brief？给到广告公司或者内部设计的 brief 长什么样？
- **follow-up** [deep_probe]：你给过 brief 但出来的创意完全不对的经历吗？事后复盘下问题在 brief 还是协作？
- **评分要点**：brief 是否包含战略 / 受众 / 不变的元素 / 可发挥的空间；能否区分"brief 不清"和"协作问题"。

### 11. 节奏控制
- **base** [standard]：一个 campaign 通常分几波节奏（预热 / 高潮 / 长尾）？你怎么设计节奏让效果最大化？
- **follow-up** [deep_probe]：节奏之间衔接出问题的经历吗？比如预热做太狠导致正式发布反而平淡。
- **评分要点**：节奏设计是否结合用户决策周期；能否预见节奏间的"挤压效应"。

### 12. 跨部门 campaign 整合
- **base** [standard]：大型 campaign 需要市场 / 产品 / 销售 / 客服联动。你怎么做跨部门整合？
- **follow-up** [deep_probe]：哪个部门最难对齐？你怎么解决的？
- **评分要点**：能否清晰描绘各方诉求和约束；推进是否同时管理目标和关系。

## 维度：渠道增长 (channel_growth)

### 13. 渠道选型
- **base** [intro]：你过往用过哪些营销 / 投放渠道？最熟的是哪个？为什么这个最熟？
- **follow-up** [standard]：你怎么决定一个新产品 / 新活动选哪几个渠道？
- **follow-up** [deep_probe]：你曾经停掉过一个渠道吗？为什么停？停了之后整体效果有变化吗？
- **评分要点**：渠道选型是否结合受众重叠 / 单位成本 / 衡量精度；能否承担"砍掉看似有效的渠道"。

### 14. 投放优化
- **base** [standard]：你做过付费投放吗？你怎么衡量一个渠道 / 创意的健康度？
- **follow-up** [deep_probe]：你最有印象的一次投放优化是怎么做的？关键变量是 creative、人群、出价、还是 landing？
- **评分要点**：能否拆解 CTR / CVR / CPA / LTV 各层指标；能识别瓶颈而非全盘调整。

### 15. ROI / LTV 思维
- **base** [standard]：渠道 ROI 怎么算才算对？短期 ROI 和长期 LTV 怎么平衡？
- **follow-up** [deep_probe]：你有没有过为了短期 ROI 放弃长期更优渠道的情况？复盘下当时的决策。
- **评分要点**：能否区分新客 CAC / 老客 LTV / 自然流量贡献；理解归因模型本身的不确定性。

### 16. 私域与公域
- **base** [standard]：你做过私域运营吗？私域和公域投放在你的体系里是什么关系？
- **follow-up** [deep_probe]：私域承接公域流量时，转化率有没有出乎你预期？为什么？
- **评分要点**：能否把私域 / 公域看成完整漏斗；理解信任迁移和场景切换的损耗。

## 维度：内容创意 (content_creativity)

### 17. 内容生产链路
- **base** [intro]：你过往内容生产链路是什么样？从想法到上线大概几步？
- **follow-up** [standard]：你怎么平衡"产出量"和"内容质量"？
- **follow-up** [deep_probe]：产出量上不去时你的瓶颈通常在哪——idea / 写作 / 设计 / 审批？
- **评分要点**：流程描述是否具体可操作；瓶颈识别是否真实而非"哪都难"。

### 18. 内容创意来源
- **base** [standard]：你的内容 idea 通常从哪来——用户访谈、热点、竞品、还是自己积累？
- **follow-up** [deep_probe]：哪一类来源最容易出爆款？这是为什么？
- **评分要点**：能否区分不同 idea 来源的命中率和成本；理解"创意可遇不可求"但仍可优化期望值。

### 19. 文案与表达
- **base** [standard]：你写过最满意的一篇文案 / 标题是什么？为什么满意？
- **follow-up** [deep_probe]：满意是因为写得漂亮还是因为效果好？这两个有没有冲突过？
- **评分要点**：能否区分"自我满意"和"用户共鸣"；在两者冲突时倾向于用户视角。

### 20. 内容效果归因
- **base** [standard]：内容数据涨了，怎么归因——是选题、写法、时机、还是分发？
- **follow-up** [deep_probe]：跑出爆款之后怎么避免"复制爆款失败的失望"？
- **评分要点**：归因是否区分必然 vs 偶然因素；理解爆款的随机性但仍提取可复用要素。

### 21. 内容与品牌的统一
- **base** [standard]：内容追求传播效果和保持品牌调性有时候冲突。你怎么处理？
- **follow-up** [deep_probe]：有过为了流量妥协调性、事后后悔的经历吗？
- **评分要点**：能否建立"调性底线"；理解短期流量和长期品牌资产的关系。

## 通用追问触发器

- 候选人说"我们 campaign 触达了 XX 万人 / 曝光了 XX 亿" → 追问"触达里多少是目标人群？转化率？品牌认知是否真的提升？"
- 候选人说"投放 ROI 很高" → 追问"归因模型用的什么？last-click 还是 multi-touch？自然流量扣了吗？"
- 候选人说"我们的内容很受欢迎" → 追问"看哪些数据知道的？分享 / 评论 / 收藏 / 复访哪个最重要？"
- 候选人说"我做了一次成功的品牌活动" → 追问"这次活动 6 个月后还有什么留痕？品牌指标 / NPS / 心智占位有变化吗？"
- 候选人说"我们的创意很有创新" → 追问"创新是和谁比？用户能感受到吗？还是只有内部觉得新？"
