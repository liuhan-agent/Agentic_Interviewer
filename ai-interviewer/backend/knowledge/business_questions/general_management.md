# 通用管理 题库

面向 C 端用户准备团队管理岗（团队 leader / 部门经理 / 业务负责人 / 总监）面试的检索种子题。题目以"请结合你过往真实带过的团队 / 项目 / 决策"为主轴。每组题目包含 base + 2-3 个渐进式 follow-up，配套 2-3 条评分要点。

难度标签：
- `intro` 开场或背景题
- `standard` 主战场，需要讲清"目标 / 策略 / 团队动作 / 结果"
- `deep_probe` 深挖追问，要求量化或暴露真实判断和承担

## 维度：目标设定 (goal_setting)

### 1. 目标拆解
- **base** [intro]：你过往接到一个年度 / 季度目标后，怎么拆给团队？
- **follow-up** [standard]：拆解过程里你最常遇到的卡点是什么——目标本身不清晰、还是拆不到个人？
- **follow-up** [deep_probe]：拆解之后团队对目标的理解和你的预期一致吗？不一致时怎么处理？
- **评分要点**：拆解是否结构化（业务结果 → 关键路径 → 部门动作 → 个人动作）；能否承担"目标本身需要先澄清"。

### 2. 优先级管理
- **base** [standard]：团队同时面对多个高优先级时，你怎么决定真正聚焦的几件？
- **follow-up** [deep_probe]：你做过最难的一次"放弃某个看起来重要的目标"是什么？说服上级和团队的关键动作？
- **评分要点**：能否区分"要做的"和"必须做的"；放弃决策是否有清晰理由。

### 3. 资源配置
- **base** [standard]：人力 / 预算有限的情况下，你怎么决定把资源给哪个项目 / 谁？
- **follow-up** [deep_probe]：你曾经"资源给错了人或项目"的复盘是什么？怎么调整的？
- **评分要点**：资源配置是否结合战略 / ROI / 人才发展；能承认配置错误并复盘。

### 4. KPI / OKR 设计
- **base** [standard]：你怎么给团队设计 KPI / OKR？怎么避免"指标涨了但业务没变好"？
- **follow-up** [deep_probe]：你设计过被钻空子的指标吗？后来怎么调整？
- **评分要点**：能否设计"对的指标"而非"好看的指标"；理解指标会被博弈并设计反作弊。

## 维度：团队领导 (team_leadership)

### 5. 团队组建
- **base** [intro]：你从零搭建过团队吗？前 3 个 hire 的标准是什么？
- **follow-up** [standard]：你的团队画像里"必须有"和"补充性"分别是什么？
- **follow-up** [deep_probe]：你招过最让你后悔的一个 hire 是什么类型？事后看哪些信号本应识别？
- **评分要点**：能否区分"硬性能力门槛"和"补充性多样化"；hiring 反思是否真诚。

### 6. 人才培养
- **base** [standard]：你过往培养过的某个团队成员，你做过什么动作让他从 A 长到 B？
- **follow-up** [deep_probe]：成长是他本身的潜力 + 你的推动还是更多机会？怎么区分？
- **评分要点**：能否承认"成长不全靠 leader"；理解机会、潜力、辅导的相互关系。

### 7. 激励与认可
- **base** [standard]：你怎么激励团队？除了钱和晋升你还有哪些方式？
- **follow-up** [deep_probe]：你过往激励失效的案例是什么？为什么对这位成员失效？
- **评分要点**：激励是否结合个体 motivator（成长 / 影响力 / 自主 / 成就 / 归属）；能识别激励的局限性。

### 8. 离职与挽留
- **base** [standard]：你的核心成员提出离职时，你怎么判断挽留还是放手？
- **follow-up** [deep_probe]：挽留成功的人后来真的留下来发展得很好吗？挽留失败的呢？
- **评分要点**：能否兼顾个人意愿和组织代价；理解挽留的"信任银行"动用。

### 9. 让人离开
- **base** [standard]：你做过让一位绩效不达标的成员离开的决定吗？怎么准备的？
- **follow-up** [deep_probe]：决定下来后这位成员的状态、团队的反应、你自己的感受？
- **评分要点**：能否兼顾决策的明确性和个体尊严；理解"留差人对好人的伤害"。

## 维度：决策判断 (decision_making)

### 10. 复杂决策框架
- **base** [intro]：你做重要决策时通常用什么框架——拍脑袋、列优劣、定量分析、还是别的？
- **follow-up** [standard]：举一个最复杂的决策——选项是什么、你的判断过程、最后选了什么、为什么？
- **follow-up** [deep_probe]：那个决策事后看是对的吗？哪一步如果重来你会改？
- **评分要点**：能否区分"决策质量"和"结果"（好决策也可能坏结果）；事后复盘真诚而非自我证明。

### 11. 不确定性下的判断
- **base** [standard]：信息不全 / 时间紧时你怎么决策？
- **follow-up** [deep_probe]：你过往做过哪些"早期信号 + 直觉"的决策最后被验证是对的？关键直觉来自哪？
- **评分要点**：能否在不确定下行动而非瘫痪；理解直觉源自经验积累并能被分析。

### 12. 数据 vs 直觉
- **base** [standard]：数据指向 A 但你的直觉指向 B 时，你怎么处理？
- **follow-up** [deep_probe]：你信了直觉而违背数据的决策里，最后赢的多还是输的多？为什么？
- **评分要点**：能否系统比较数据和直觉的可靠场景；不简单"二选一"。

### 13. 决策回滚
- **base** [standard]：你做过的决策被证明是错的时，你怎么处理？
- **follow-up** [deep_probe]：错误决策的代价是被你独自承担、还是和团队共同分担？怎么决定？
- **评分要点**：能否在错误下保持心理稳定；理解"承担"对团队信任的长期建设。

## 维度：执行管理 (execution_management)

### 14. 项目推进
- **base** [intro]：你怎么 track 一个项目的进度？什么频率 review、什么时候介入？
- **follow-up** [standard]：你过往推过最复杂的项目是什么？关键风险点在哪？
- **follow-up** [deep_probe]：项目偏离原计划时你怎么决定 stay 还是 pivot？
- **评分要点**：推进机制是否轻重适度（不要过度管控）；面对偏离能区分"调整 vs 放弃"。

### 15. 委托与放权
- **base** [standard]：你哪些事亲自做、哪些委托给团队？决定标准是什么？
- **follow-up** [deep_probe]：你曾经"过度放权"或"过度抓"的案例分别是什么？怎么调整的？
- **评分要点**：能否结合事项重要性 / 团队能力做委托决策；自我反思真诚。

### 16. 跨周期目标管理
- **base** [standard]：你怎么平衡"完成本季度 KPI"和"为下个周期蓄能"？
- **follow-up** [deep_probe]：你曾经为了短期 KPI 透支过长期项目吗？事后看值不值？
- **评分要点**：能否处理短期 / 长期 KPI 冲突；理解"透支"的代价并能量化。

### 17. 复盘与改进
- **base** [standard]：你团队的项目复盘机制是什么样？怎么保证复盘出真问题？
- **follow-up** [deep_probe]：复盘里发现的问题真的被改掉了多少？怎么追踪？
- **评分要点**：复盘是否结构化（事实 / 原因 / 改进 / 责任）；改进项是否有闭环。

## 维度：跨部门协同 (cross_functional_alignment)

### 18. 部门间冲突
- **base** [intro]：你的部门和其他部门目标冲突时，你怎么处理？
- **follow-up** [standard]：你过往最难协调的一次跨部门冲突是什么？关键转折点在哪？
- **follow-up** [deep_probe]：那次冲突解决之后两个部门长期合作关系如何？
- **评分要点**：能否区分"利益冲突"和"沟通不畅"；处理是否兼顾"赢得合作"和"避免被坑"。

### 19. 向上沟通
- **base** [standard]：你怎么向老板 / 高层汇报项目进展、风险、和资源诉求？
- **follow-up** [deep_probe]：你的汇报方式有没有因为某次踩坑做过调整？比如"老板更想看 X 而不是 Y"？
- **评分要点**：汇报是否结构化（结论 → 证据 → 风险 → 求助）；能否根据听众调整内容密度。

### 20. 影响力推进
- **base** [standard]：你需要推动的事情没有正式权威（比如不是你直管团队），怎么推？
- **follow-up** [deep_probe]：你最有印象的一次"借势 / 借力"推动是什么？关键动作是哪一步？
- **评分要点**：能否善用人际影响力而非依赖权威；理解"借势"的政治边界。

### 21. 文化建设
- **base** [standard]：你过往参与建设过什么团队 / 部门的文化要素？怎么从口号变成行为？
- **follow-up** [deep_probe]：你建设的文化里有没有过被自己违背的时刻？怎么处理？
- **评分要点**：能否把文化变成具体行为（不是 slogan）；自我反思真诚（leader 也会违背自己提的标准）。

## 通用追问触发器

- 候选人说"我带的团队完成了 XX 业务目标" → 追问"团队规模？目标完成率？团队成员后来发展怎么样？"
- 候选人说"我做了一个艰难决策" → 追问"决策时间多久？关键支持者 / 反对者各是谁？事后这个决策的代价分摊到哪？"
- 候选人说"我推动了一个跨部门项目" → 追问"项目规模？涉及多少人？最难推的一步是哪一步？"
- 候选人说"我的团队氛围很好" → 追问"通过什么数据看到的？eNPS？流失率？团队成员的反馈？"
- 候选人说"我培养了 X 个人" → 追问"这些人现在在做什么？他们的成长有多少是你的贡献？"
