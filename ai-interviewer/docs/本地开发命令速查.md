# 本地开发命令速查

这份文档记录 AI 面试官项目在 Windows PowerShell 下的常用启动、关闭和检查命令。

当前推荐的本地开发方式是：

```text
Docker Desktop
  -> Postgres / Redis / Chroma

Windows 本机
  -> FastAPI 后端 :8000
  -> Next.js 前端 :3000
```

也就是说，前端和后端不在 Docker 里跑；Docker 只负责基础服务。

## 1. Docker Desktop

启动 Docker Desktop：

```powershell
Start-Process "C:\Program Files\Docker\Docker\Docker Desktop.exe"
```

检查 Docker 是否可用：

```powershell
docker info
```

能看到 `Server:` 信息就说明 Docker Desktop 已经启动成功。

关闭 Docker Desktop：

```powershell
Stop-Process -Name "Docker Desktop" -Force
```

也可以在 Windows 右下角托盘找到 Docker 图标，右键选择 `Quit Docker Desktop`。

## 2. 基础服务

进入后端目录：

```powershell
cd D:\Agent\Agentic_Interviewer\ai-interviewer\backend
```

启动 Postgres、Redis、Chroma：

```powershell
docker compose up -d postgres redis chroma
```

查看 compose 服务状态：

```powershell
docker compose ps
```

查看正在运行的 Docker 容器：

```powershell
docker ps
```

临时停止基础服务：

```powershell
docker compose stop
```

重新启动已停止的基础服务：

```powershell
docker compose start
```

关闭并移除本项目的基础服务容器和网络：

```powershell
docker compose down
```

一般开发时用：

```powershell
docker compose up -d postgres redis chroma
```

不用时用：

```powershell
docker compose down
```

## 3. 后端项目

进入后端目录：

```powershell
cd D:\Agent\Agentic_Interviewer\ai-interviewer\backend
```

激活 Python 虚拟环境：

```powershell
.\.venv\Scripts\Activate.ps1
```

安装或刷新后端依赖：

```powershell
pip install -e ".[dev,voice]"
```

初始化知识库：

```powershell
python -m app.scripts.seed_kb
```

导入结构化题库和 Skills Playbook：

```powershell
python -m app.scripts.import_question_seeds --archive-missing
python -m app.scripts.import_skill_playbooks --archive-missing
```

这两个导入命令是显式运维动作；后端启动不会自动导入内容。

运行命令行 demo：

```powershell
python -m app.scripts.run_demo
```

启动后端 API：

```powershell
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

检查后端健康状态：

```powershell
Invoke-WebRequest http://127.0.0.1:8000/health -UseBasicParsing
```

运行后端测试：

```powershell
pytest tests/unit -q
```

如果后端是在当前 PowerShell 窗口前台启动的，按 `Ctrl+C` 关闭。

如果后端在后台运行，先查端口对应进程：

```powershell
Get-NetTCPConnection -LocalPort 8000 -State Listen | Select-Object LocalPort,OwningProcess
```

然后停止对应进程：

```powershell
Stop-Process -Id <PID>
```

## 4. 前端项目

进入前端目录：

```powershell
cd D:\Agent\Agentic_Interviewer\ai-interviewer\frontend
```

安装前端依赖：

```powershell
npm install
```

启动前端开发服务器：

```powershell
npm run dev -- --hostname 127.0.0.1 --port 3000
```

打开页面：

```text
http://127.0.0.1:3000
```

运行类型检查：

```powershell
npm run typecheck
```

运行 lint：

```powershell
npm run lint
```

生产构建：

```powershell
npm run build
```

如果前端是在当前 PowerShell 窗口前台启动的，按 `Ctrl+C` 关闭。

如果前端在后台运行，先查端口对应进程：

```powershell
Get-NetTCPConnection -LocalPort 3000 -State Listen | Select-Object LocalPort,OwningProcess
```

然后停止对应进程：

```powershell
Stop-Process -Id <PID>
```

打开 Docker Desktop：

```powershell
Start-Process "C:\Program Files\Docker\Docker\Docker Desktop.exe"
```

```powershell
cd D:\Agent\Agentic_Interviewer\ai-interviewer\backend
docker compose up -d postgres redis chroma
```

导入题库和 playbook：

```powershell
python -m app.scripts.import_question_seeds --archive-missing
```

```text
http://127.0.0.1:3000
```

## 7. 快速排查

检查 Docker：

```powershell
docker info
docker ps
```

检查基础服务：

```powershell
cd D:\Agent\Agentic_Interviewer\ai-interviewer\backend
docker compose ps
```

检查端口：

```powershell
Get-NetTCPConnection -LocalPort 3000,8000,5433,6380,8100 -State Listen
```

检查后端：

```powershell
Invoke-WebRequest http://127.0.0.1:8000/health -UseBasicParsing
```

检查前端：

```powershell
Invoke-WebRequest http://127.0.0.1:3000 -UseBasicParsing
```

检查 Admin 观察面：

```text
打开 http://127.0.0.1:3000/admin
确认 Question Bank 和 Skills Playbook 卡片都有 active 数据
```

如果 `docker info` 只有 `Client` 没有正常的 `Server` 信息，说明 Docker Desktop 还没启动好。

如果前端能打开但提交失败，优先检查后端 `http://127.0.0.1:8000/health`。

如果后端启动失败，优先检查 Postgres、Redis、Chroma 是否已启动。
